# skills

A collection of reusable AI agent skills for coding, documentation, and software development workflows.

## Structure

```text
skills/
├── conventional-commits/
│   └── SKILL.md
└── python-docstrings/
    └── SKILL.md
```

## Usage

Install the skills using the [Skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add git@github.com:LucasKiraly/skills.git
```
