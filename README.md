# skills

Reusable AI agent skills and workflow instructions for coding, documentation, and development tasks.

## Structure

```text
skills/
├── conventional-commits/
│   └── SKILL.md            # Conventional Commits guidelines
└── python-docstrings/
    └── SKILL.md            # Google-style Python docstring guidelines
```

## Usage

Install the skills using the [Skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add git@github.com:LucasKiraly/skills.git
```

Alternatively, clone the repository to manage the skills manually:

```bash
git clone git@github.com:LucasKiraly/skills.git
```
